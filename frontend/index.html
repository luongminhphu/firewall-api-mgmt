Chưa gọi được API? Kiểm tra 3 điểm này trên firewall
  1. Bật API: System → Administration → API, tick API Configuration.
  2. Allowed IP: thêm IP của máy chủ chạy mini app (lỗi 534 nghĩa là chưa thêm).
  3. Quyền: tài khoản API cần quyền ghi Hosts & Services (lỗi 599 là thiếu quyền).
