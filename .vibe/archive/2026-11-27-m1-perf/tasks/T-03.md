# T-03: Tìm Audit log đúng (lọc trước LIMIT) + index action
## Mục tiêu
`GET /api/audit?q=` tìm được bản ghi cũ hơn `limit` dòng mới nhất; thêm index `audit_logs(action)` cho DB mới và DB cũ.
## Bối cảnh cần biết
- Quyết định: D1 (không đổi response/API), D2, D5 trong .vibe/PLAN.md. Challenge: C-04, C-05.
- Quy tắc CLAUDE.md: 7 (schema tự tạo khi khởi động, chạy SQLite + PostgreSQL), 8 (contract_test không ghi lại snapshot), 10.
## Phạm vi
- Được sửa: backend/app/modules/audit/router.py, backend/app/core/models.py (chỉ AuditLog.action thêm index=True), backend/app/core/db.py (chỉ thêm tạo index cho bảng đã tồn tại), tạo tests/audit_search_test.py.
- KHÔNG được sửa: hình dạng response (`{"rows", "count"}`), audit.csv, file khác.
## Yêu cầu chi tiết
1. audit_list: dựng một stmt; nếu action → where action; nếu q → where or_(AuditLog.target.icontains(q, autoescape=True), AuditLog.firewall_name.icontains(q, autoescape=True), AuditLog.reason.icontains(q, autoescape=True)); rồi order_by(desc(id)).limit(limit). Bỏ lọc Python. Giữ nguyên tham số và kiểu.
2. models.py: `action` thêm `index=True` (create_all tạo ix_audit_logs_action cho DB mới).
3. db.py: sau vòng thêm cột trong hàm nâng cấp, chạy `CREATE INDEX IF NOT EXISTS ix_audit_logs_action ON audit_logs (action)` (cú pháp hợp lệ cả SQLite và PostgreSQL). Giữ tối giản, không viết cơ chế index chung.
4. Test tests/audit_search_test.py (in PASS/FAIL, exit 1 khi lỗi; header `# Chạy: bash tests/run_e2e.sh tests/audit_search_test.py`): chèn > limit bản ghi audit (qua ORM hoặc qua API đăng nhập — xem tests/users_test.py để biết cách đăng nhập/token), bản ghi có target đặc biệt nằm cũ nhất; `/api/audit?q=<target>&limit=5` phải trả nó. Kiểm: q chứa `_` không khớp ký tự bất kỳ (vd target "FWxHCM" không khớp q="fw_hcm", "FW_HCM" thì khớp); không phân biệt hoa thường ASCII; action+q kết hợp; count == len(rows). Kiểm index tồn tại (sqlalchemy inspect get_indexes).
5. Ghi chú trong test: SQLite lower() không xử lý chữ hoa có dấu; PostgreSQL ILIKE thì có — không kiểm chữ hoa có dấu trên SQLite.
